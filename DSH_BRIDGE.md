# DSH Bridge

Jembatan kerja dua arah Kiro <-> DSH di branch `dsh/kiro`.

- Kiro: commit diawali `[kiro]`, push ke sini, tulis cara uji di KIRI_NOTES.md.
- DSH: commit diawali `[dsh]`, review + perbaikan langsung di branch ini.
- Aturan: `git pull --rebase` sebelum edit; tidak pernah push ke `main`.

Aktif sejak 2026-11-07.
